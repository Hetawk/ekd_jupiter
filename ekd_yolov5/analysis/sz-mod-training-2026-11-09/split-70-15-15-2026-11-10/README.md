# Exploratory 70/15/15 SafeZone training run

This folder contains the results of the YOLOv5s experiment using the alternate
70/15/15 split. The complete generated split is in
[`datasets/sz-mod-70-15-15/`](../../../datasets/sz-mod-70-15-15/); the dataset
config and split manifest are copied into `dataset/` here as well.

## Dataset and run

- Images: 622 train / 133 validation / 134 test (889 total).
- Split seed: 42; images were stratified by class presence, with exact image
  duplicates checked before assignment.
- Model: YOLOv5s initialized from `yolov5s.pt`; 100 epochs completed.
- Training: 640-pixel images, batch size 8, seed 42, GPU 3 (Tesla T4).
- Best checkpoint: `training/weights/best.pt` (about 14 MB).
- Test split: 134 images and 150 object labels.

This is exploratory, not an independent final test. It was generated by
repartitioning the existing 889 images; the old validation/test images,
including the old test images used in previous comparisons, were repartitioned
among all three new splits. Of the original 70 test images, 46 moved into new
training, 12 into validation, and 12 remain in the new test split. Therefore,
its test metrics must not be interpreted as an unbiased estimate of
generalization or compared directly to the old test metrics.

## Evaluation

Metrics are proportions; for example, mAP@0.5 of 0.893 is 89.3%. The selected
checkpoint's validation and exploratory test results are:

| Split | Class | Images | Labels | Precision | Recall | mAP@0.5 | mAP@0.5:0.95 |
|---|---|---:|---:|---:|---:|---:|---:|
| Validation | All | 133 | 150 | 0.879 | 0.833 | 0.860 | 0.577 |
| Validation | Scissors | 133 | 68 | 0.943 | 0.971 | 0.957 | 0.727 |
| Validation | Earbuds | 133 | 82 | 0.815 | 0.695 | 0.762 | 0.428 |
| Test (exploratory) | All | 134 | 150 | 0.900 | 0.851 | 0.893 | 0.618 |
| Test (exploratory) | Scissors | 134 | 72 | 0.985 | 0.907 | 0.974 | 0.741 |
| Test (exploratory) | Earbuds | 134 | 78 | 0.816 | 0.795 | 0.812 | 0.496 |

The expanded validation and test splits provide more evaluation images than
the original 70-image splits. However, the training set is 127 images smaller,
and results on the new test set are not directly comparable to the prior
experiments because the data composition changed.

## Contents

- `training/`: training results CSV/plot, configurations, TensorBoard events,
  validation visualizations, and `weights/best.pt`. The redundant `last.pt`
  was removed to save space.
- `validation-evaluation/` and `test-evaluation/`: curves, confusion matrices,
  and prediction/label visualizations for the selected checkpoint.
- `metrics.csv`: validation and exploratory test metrics by class.
- `logs/`: full training and evaluation console logs.
- `dataset/`: exact YOLOv5 YAML and split manifest used for the run.

## Reproduce evaluation on `ci2p`

From the YOLOv5 checkout, activate the SafeZone runtime and define the
`yolo_run` helper from the [project guide](../../../docs/README.md). Then
run:

```bash
yolo_run val.py --data datasets/sz-mod-70-15-15/data.yaml \
  --weights runs/train/sz-mod-s-70-15-15-100-20261110/weights/best.pt \
  --img 640 --device 3
yolo_run val.py --data datasets/sz-mod-70-15-15/data.yaml \
  --weights runs/train/sz-mod-s-70-15-15-100-20261110/weights/best.pt \
  --img 640 --task test --device 3
```
